# 颜色模型、透明度及分离约定
图像为[H,W,3]线性RGB、范围[0,1]，valid像素与缺测分开。涂抹记录含id/revision/像素坐标及kind=foreground/background/unknown；unknown是撤掉该条约束而不是清掉别的记录。不同活动记录在同像素有相反确定类型即冲突。硬前景alpha=1，硬背景alpha=0。窗口是以像素为中心的3×3有效图像邻域，跨块但不跨图像；不完整的缺测邻域不能补0当有效。
alpha目标为局部线性颜色模型：对每个完整有效窗口w，最小化sum_i_in_w(alpha_i-a_w^T I_i-b_w)^2+epsilon*||a_w||2^2，所有窗口求和，并守住硬涂抹。epsilon为可训练正参数，小样本1e-3；消去a/b或同时求解均可，不规定求解器。目标<=最优容差下选最小Euclidean范数alpha；无硬约束且不与约束域相连的分量无alpha确定资格，不把最小范数0解释成可靠背景。alpha允许范围[0,1]，约束活跃切换处不声称普通导数。
固定已接受alpha后，颜色目标为sum_valid||I-alpha*F-(1-alpha)*B||2^2+lambda*sum_adj(||F_i-F_j||2^2+||B_i-B_j||2^2)，每通道独立，邻接为四邻有效像素；lambda小样本0.02，可训练。颜色限制0<=F,B<=1；已知颜色锚点直接固定。接受混合重建每像素Linf<=request.reconstruction_tol，同时约束系统对所交付F的可辨识性成立：消去固定变量后，将设计矩阵奇异值<1e-5的右奇异向量（含零空间）投影到该像素F坐标，投影范数均<=1e-7；不相关B的自由方向不单独否决F。alpha<=1e-4位置的F默认为不可辨识，除非有明确前景颜色锚点；alpha>=1-1e-4时B同理。换底为alpha*F+(1-alpha)*new_background，正式交付需alpha和所用F有资格，不要求无关B可辨识。
训练损失包括有效混合重建及用户有合成F真值的合格像素，分母分别是两类实际有效标量权重和；不可辨识F不进入F损失，但有资格的混合重建仍可用。VJP到图像、epsilon和lambda，不对涂抹离散身份或硬值求导；在约束不切换且系统唯一的域接受普通VJP，其他域明确拒绝。alpha和颜色残差各<=1e-7相对，图像atol1e-6/rtol1e-5，差分rtol1e-3。
CPU范围至128×128，图块16×16，最多32涂抹记录；内存临时区32MiB，允许稀疏结构，不允许全图稠密系统。小图含半透明混合、缺测和近同色区域，操作记录只给输入；读取工具不预先计算alpha或分离颜色。
